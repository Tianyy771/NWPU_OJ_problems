# Blackwater 题解：114514、线性相关与最小非空异或

> 面向刚接触线性基的同学，建议先理解“为什么区间长度达到 18 就能异或出 0”，再看线性基的代码。
>
> [返回题面](./Blackwater.md) · [独立标准程序](./std.cpp) · [样例测试](./tests/sample.in)

## 一、题目到底在问什么？

给你一个整数数组，每次询问一个区间 $[l,r]$，你需要在这个区间中选出**至少一个下标**，把选中的数字异或起来，问能得到的最小整数。

注意：

- 一个下标最多选择一次。
- 可以选一个，也可以选多个。
- **不能什么都不选。** 空集的异或一般定义为 0，但本题不允许空集，所以不能直接把 0 当成答案。
- 每次询问独立，不会修改数组。

比如区间只有数字 5 和 9，合法选择和结果是：

| 选择 | 异或值 |
| --- | ---: |
| 只选 5 | 5 |
| 只选 9 | 9 |
| 5 和 9 都选 | 12 |

所以答案是 5。

如果区间变成 5、9、12，由于 $5\oplus9\oplus12=0$，就可以合法地得到 0。既然异或结果不可能是负数，答案就是 0。

## 二、暴力枚举为什么不行？

假设一次询问的区间长度是 $L$。

每个位置只有选或不选两种状态，所以一共有 $2^L$ 个子集；去掉空集，还剩下 $2^L-1$ 个可选方案。

如果 $L=30$，就已经有十亿级别的方案，更不用说 $n\le2\times10^5$ 了。

面对区间询问，我们通常会想线段树、前缀线性基等复杂技巧。可是这道题有一个非常不寻常的数据范围：

$$
1\le a_i\le114514.
$$

没错，就是那个数字。🤣 它在本题里不仅是整活，还是解题的突破口。

## 三、关键观察：17 个二进制位

因为：

$$
2^{16}=65536<114514<131072=2^{17},
$$

所以所有 $a_i$ 都可以用**不超过 17 个二进制位**表示。

把整数看成由 0 和 1 构成的向量，就能把异或看成模 2 加法。

例如：

$$
5=(00101)_2,\qquad 9=(01001)_2,\qquad12=(01100)_2.
$$

三者异或为 0，对应的就是三个二进制向量相加为零向量。

现在回顾线性代数中一个重要事实：

> 在一个至多 17 维的向量空间里，任意 18 个向量必然线性相关。

所谓**线性相关**，在异或问题中就是：

**存在一组至少包含一个元素的下标，使这些位置上的数异或起来等于 0。**

因此，只要区间长度满足：

$$
L=r-l+1\ge18,
$$

就一定存在一个合法的非空子集异或得到 0。

因为任何非负整数都不可能比 0 更小，所以：

$$
\boxed{L\ge18\ \Longrightarrow\ \text{答案}=0.}
$$

### 这里特别容易误解

这并不是说“随便 18 个数全部异或起来就等于 0”，而是说“这 18 个数中**一定存在某个非空子集**，异或起来等于 0”。

两句话完全不一样。

### 那为什么不是 17 呢？

考虑这 17 个数：

$$
1,2,4,8,\ldots,65536.
$$

它们恰好在 17 个不同的二进制位上各有一个 1。任选非空子集，总有至少一个二进制位留下 1，因此异或不可能为 0。

所以能直接保证答案为 0 的长度阈值，准确来说就是 **18**。

## 四、原来只需要处理长度不超过 17 的区间！

经过上面的推导，每次询问可以直接分类：

1. **区间长度至少 18：** 输出 0，复杂度 $O(1)$。
2. **区间长度至多 17：** 只需要处理最多 17 个数字。

这是本题最大的降维。

于是，原先巨大的数组长度已经没有那么可怕了：每次真正需要执行运算的数字最多只有 17 个。

### 其实暴力也能做

短区间最多只有 $2^{17}-1=131071$ 个非空子集。

题目还限制了 $q\le100$，所以总共最多也就枚举约 1310 万个子集。如果用最低位递推维护每个子集的异或值，子集异或可以在 $O(1)$ 内得到，因此枚举法也能通过。

不过题目本身很适合拿来学习线性基，我们接下来用线性基写一个更快的解法。

## 五、线性基：先理解它存的是什么

你可以把线性基看成一个**异或意义下的向量集合**：它保存少量线性无关的数，任意已插入数字的异或组合都可以由它们表示。

例如：

$$
5\oplus9=12.
$$

如果已经有了 5 和 9，再加入 12 并不会增加新的独立方向，因为 12 可以用前两个数异或出来。

我们用长度为 17 的数组 base 维护线性基。其中：

**base[b] 非零时，表示它最高的二进制 1 位位于第 b 位。**

比如：

- 5 的二进制是 0101，最高位 1 在第 2 位；
- 9 的二进制是 1001，最高位 1 在第 3 位。

所以先插入 5 和 9 后，可以有 base[2]=5、base[3]=9。

### 如何插入一个数？

设新数字为 x，从最高位向最低位扫描。

1. 如果 x 在这一位是 0，就跳过。
2. 如果这一位是 1，而且对应 base[b] 为空，就把 x 放进去，插入结束。
3. 如果这一位是 1，但 base[b] 已经存了一个数，就让 x 异或 base[b]，把这一位的 1 消掉，再往低位继续。

为什么能消掉？因为 $1\oplus1=0$。

这就是线性基插入的核心：**用已经存下来的向量消去新向量的最高位。**

### 插入 12 时发生了什么？

已经有：

- base[3]=9；
- base[2]=5。

插入 12：

1. 12 的最高位是第 3 位。
2. 第 3 位已有 9，于是 12 异或 9 得到 5。
3. 5 的最高位是第 2 位。
4. 第 2 位已有 5，于是再异或 5，最后得到 0。

也就是说：

$$
12\oplus9\oplus5=0.
$$

于是我们找到了一个**真正的、非空的、异或值为 0 的子集**。

## 六、如何判断非空子集能否异或出 0？

这一步一定要与“线性基能够表示 0”区分开。

线性空间里，0 本来就可以由**什么都不选**得到。但本题不能选空集。

我们需要判断的是：**是否有一组非空的原始元素，异或和为 0**。

线性基有一个很方便的判定方法：

- 如果一个新数字最终能成功放入某个空的 base[b]，它带来了新的线性独立方向。
- 如果一个新数字最终被消成 0，说明它已经可以由此前的数字异或表示。

后一种情况下，取此前代表它的那个子集，再把这个新数字放进去，就得到一个**至少包含新数字的非空子集**，其异或结果为 0。

所以代码中只需要一个布尔变量 hasZero。

一旦某次插入消成 0，就将 hasZero 设成 true。

如果 hasZero 为 true，本次询问的答案立刻确定为 0。

## 七、如果没有非空零异或子集，最小值怎么求？

这个地方乍看需要更复杂的线性基技巧，其实非常简单。

设线性基中所有非零基向量，其最高位互不相同。

考虑从这些基向量里挑出一个非空集合做异或。

如果被选中基向量的最高位中，最大的那一位是 b，那么异或结果在第 b 位一定为 1。

为什么？

因为只有最高位为 b 的那个基向量在第 b 位是 1；其他被选中的基向量最高位都低于 b，不可能把这一位抵消掉。

因此：

> **一个非零基向量组合，其异或结果的最高位，等于被选中基向量中最大的最高位。**

我们要最小化最终的非负整数，就要让它的最高位尽量低。

假设线性基里最高位最低的那个非零基向量是 base[k]。

- 只选它，得到一个最高位为 k 的合法值；
- 如果加入任何其他非零基向量，其他基向量的最高位都比 k 高，最终异或值也会有更高的最高位，必然更大。

所以：

**当不存在非空子集异或为 0 时，答案就是从低位到高位找到的第一个非零 base[b]。**

不用重新消元，也不用再枚举一遍组合。

例如，基向量为 9 和 5，能得到的非零值是：

$$
5,\quad9,\quad5\oplus9=12.
$$

其中最高位最低的是 5，答案就是 5。

## 八、完整算法

对于一次询问 $[l,r]$：

1. 计算 $L=r-l+1$。
2. 如果 $L\ge18$，输出 0。
3. 否则创建一个空线性基，依次插入区间中的每个元素。
4. 如果出现线性相关（某个新元素消元到 0），输出 0。
5. 否则，从第 0 位开始找到第一个非零基向量，输出它的值。

其中第 4、5 步也可以封装成线性基的查询函数。

## 九、C++17 参考实现

下面的代码也单独保存在 [std.cpp](./std.cpp) 中。为了易读，保留了关键位置的中文注释。

~~~cpp
#include <bits/stdc++.h>
using namespace std;

// ai <= 114514 < 2^17，因此只需要考虑第 0～16 位。
constexpr int BITS = 17;

struct XorBasis {
    array<int, BITS> base{};
    bool hasZero = false; // 是否存在非空子集异或为 0

    void insert(int x) {
        for (int bit = BITS - 1; bit >= 0; --bit) {
            if (((x >> bit) & 1) == 0) continue;

            if (base[bit] == 0) {
                base[bit] = x;
                return;
            }
            x ^= base[bit];
        }

        // 新元素可由此前元素异或得到。
        // 将新元素与此前的对应子集放在一起，就得到非空异或 0。
        hasZero = true;
    }

    int minimumNonemptyXor() const {
        if (hasZero) return 0;

        // 无线性相关时，取最高位最低的那个基向量。
        for (int bit = 0; bit < BITS; ++bit) {
            if (base[bit] != 0) return base[bit];
        }

        // 每次询问至少有一个元素，因此正常情况下不会到这里。
        return 0;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;

    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) cin >> a[i];

    while (q--) {
        int l, r;
        cin >> l >> r;

        // 17 位向量空间中，任意 18 个向量必线性相关。
        if (r - l + 1 >= BITS + 1) {
            cout << 0 << '\n';
            continue;
        }

        XorBasis basis;
        for (int i = l; i <= r; ++i) {
            basis.insert(a[i]);
        }
        cout << basis.minimumNonemptyXor() << '\n';
    }
    return 0;
}
~~~

## 十、正确性证明

**引理 1：** 长度至少为 18 的区间，答案必为 0。

证明：所有输入数小于 $2^{17}$，所以它们都是 17 维二进制向量。任意 18 个向量必然线性相关，存在一个非空子集异或为 0。异或结果不可能是负数，因此 0 就是最小值。证毕。

**引理 2：** 对于短区间，线性基的 hasZero 能正确判断是否存在非空零异或子集。

证明：插入时的异或消元不会改变此前向量的张成空间。如果新向量被消为 0，说明它是此前向量的异或组合，取这个组合并加入新向量便得到一个非空的零异或子集。反之，如果没有新向量被消为 0，说明每次插入都增加了线性空间的维数，因此原向量线性无关，不存在非空零异或子集。证毕。

**引理 3：** 若不存在非空零异或子集，最低非零基向量就是最小可达值。

证明：线性基中不同非零向量的最高位不同。任意非空基向量组合的最高位等于其中最大的一项最高位。为了使结果最小，必须选择尽可能低的最高位；此时只能单独选取整个线性基中最高位最低的那个基向量。证毕。

**定理：** 算法对所有询问给出正确答案。

证明：长区间由引理 1 正确；短区间若有非空零异或子集，由引理 2 得到正确答案 0；否则由引理 3 得到最小正异或值。证毕。

## 十一、复杂度分析

设二进制位数 $B=17$。

- 读入数组： $O(n)$。
- 长区间询问： $O(1)$。
- 短区间最多插入 B 个数，每次插入最多检查 B 位： $O(B^2)$。

因此总时间复杂度：

$$
O(n+qB^2),\qquad B=17.
$$

额外空间复杂度：

$$
O(n+B).
$$

## 十二、常见错误与检查清单

1. **把空集算进去。** 如果没有真正的线性相关关系，就不能随意输出 0。
2. **以为任意 18 个数全部异或等于 0。** 正确的是存在非空子集异或等于 0。
3. **将数字限制理解为只有 16 位。** 114514 需要 17 位二进制，最高位下标是 16。
4. **长度为 17 的区间直接输出 0。** 不保证；只有长度至少为 18 才必然成立。
5. **只选最小原始元素。** 例如 $6\oplus7=1$，异或能产生比单个输入更小的数字。
6. **多个询问共用上一个线性基。** 每次询问的区间不同，线性基必须重新建立。

## 十三、总结

这道题最值得带走的不是一份线性基模板，而是三个观察：

- **看到有限的二进制位数，就考虑线性空间的维数。**
- **看到“至少选一个”与最小异或，就必须小心区分空集的 0 和线性相关产生的 0。**
- **一个维数很小的异或问题，可以使用线性基，也可能允许直接枚举全部子集。**

把 114514 塞进数据范围看似是整活，但在这里它恰好将可用数字限制在 17 位内，让看似复杂的区间查询问题瞬间变得简单。
